# الکل ایزوپروپیل برای تمیز کردن گلس؛ چند درصد و چطور؟

قبل از نصب گلس جدید، خیلی‌ها صفحه را با هر مایعی که دم دست باشد پاک می‌کنند. نتیجه گاهی حباب ریز، لکه چربی ماندگار، یا حتی آسیب به پوشش اولئوفوبیک صفحه‌ی اصلی است. ایزوپروپیل (IPA) اگر درست انتخاب و استفاده شود، یکی از تمیزکننده‌های مطمئن برای این کار است.

## چند درصد مناسب است؟

- **حدود ۷۰٪**: برای چربی اثرانگشت و آلودگی روزمره معمولاً کافی است و کمی رطوبت دارد که گردوغبار را بهتر برمی‌دارد.
- **۹۰–۹۹٪**: خشک‌تر و سریع‌تبخیرتر است؛ برای پاک کردن باقیمانده‌ی چسب گلس قبلی مفیدتر است، ولی روی پوشش ضدچربی صفحه باید با احتیاط و مقدار خیلی کم استفاده شود.

اگر فقط دستمال میکروفایبر تمیز دارید، همان را اول خشک بکشید؛ خیلی وقت‌ها نیازی به مایع نیست.

## روش امن

1. گوشی را خاموش یا حداقل اعلان‌ها را بی‌صدا کنید تا وسط کار صفحه روشن/خاموش نشود.
2. مقدار خیلی کم IPA را روی **دستمال** بزنید، نه مستقیم روی صفحه یا گلس.
3. با حرکت یک‌طرفه (نه دایره‌ای کثیف) سطح را پاک کنید.
4. چند ثانیه صبر کنید تا کاملاً خشک شود؛ بعد لایه‌ی چسب گلس را بردارید و نصب را شروع کنید.

## چیزهایی که نباید استفاده کنید

- الکل صنعتی نامشخص، شیشه‌شوی خانگی، یا عطر/ادکلن: ممکن است رنگ قاب یا پوشش صفحه را مات کند.
- دستمال کاغذی زبر: خودش خط ریز می‌گذارد؛ مخصوصاً روی گلس مات.
- مقدار زیاد مایع کنار اسپیکر، دکمه یا درز شارژ.

## اگر گلس قبلی را کنده‌اید

لکه‌ی باقیمانده گاهی چسب است، گاهی فرسودگی پوشش ضدچربی. با IPA ملایم و دستمال تمیز امتحان کنید؛ اگر هاله ماند، قبل از نصب گلس جدید بهتر است وضعیت صفحه را در نور مایل چک کنید تا حباب یا موج بعد از نصب غافلگیرتان نکند.
